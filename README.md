# Fog of War Chess Assistant

The Fog of War Chess Assistant is a unique tool that enhances gameplay in the chess variant Fog of War (also known as Dark Chess), where much of the board is hidden from view. During a game, one advantaged player can chat with the assistant to receive move suggestions that take their opponent’s tendencies into account, helping them make better-informed decisions.

## Running the Program

1. Download the zip file.

2. Open in your IDE (e.g., VSCode, PyCharm) of choice.

3. Install dependencies:
   Make sure you have Python 3 installed.
   '''
   pip install chess requests
   '''

4. Run main.py to:
   - Start the game.
   - Enter game objective or bias information.

5. As you play the game, white player can:
   - Click the 'Make Suggestion' button to receive move suggestions.
   - Click the 'Print Captured Pieces' button to print the pieces they've captured.

6. Black player can:
   - Click the 'Print Captured Pieces' button to print the pieces they've captured.
